# 模型集成

## 目标

将已验证的 INT8 TFLite 模型作为工程资源，接入 TFLM 推理任务。

## 集成清单

- 模型二进制的存储方式与链接区域。
- 模型起始地址、长度和所需对齐。
- `MicroMutableOpResolver` 或项目使用的算子注册机制。
- Tensor Arena 的大小、位置及其与应用缓冲区的关系。
- 输入采集、前处理和输出后处理的接口。
- NPU 初始化、错误处理和性能计时接口。

## 推荐验证顺序

1. 仅加载模型，确认 schema 与模型版本兼容。
2. 分配张量，记录所需 Arena 大小。
3. 写入固定参考输入，比较输出张量。
4. 接入真实输入链路。
5. 记录运行后端、耗时和内存。

不要只因模型位于 Flash 就假定可直接访问；应在实际板卡上验证存储接口初始化、可访问性和读取性能。
