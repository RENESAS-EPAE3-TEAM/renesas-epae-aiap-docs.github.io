# 算子支持检查

## 何时检查

在模型转换后、设备集成前检查算子。模型初始化失败、无法委派给 NPU 或性能异常时，也应重新确认该清单。

## 决策流程

```text
发现不支持算子
  -> 能否用受支持算子重写模型？
       是 -> 修改模型，重新转换和验证
       否 -> 评估 TFLM 自定义算子
                -> 确认 CPU 运行成本和 NPU 兼容性
```

## 必须区分

- **TFLM 可运行**：解释器存在该算子的实现。
- **NPU 可加速**：该算子及其参数满足 NPU 后端约束。

实现自定义 TFLM 算子不会自动使该算子在 Ethos-U55 上运行。需要单独确认实际执行后端。
