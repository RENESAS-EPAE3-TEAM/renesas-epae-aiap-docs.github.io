# Renesas RA8P1 AI 应用开发指南

本指南面向使用 Renesas RA8P1 开发端侧 AI 应用的工程师，覆盖模型准备、平台配置、Ethos-U55 NPU 部署、验证优化，以及与 HMI 应用的集成。

## 从哪里开始

| 你的目标 | 建议路径 |
| --- | --- |
| 第一次使用 RA8P1 AI | 平台概述 -> 开发环境 -> 快速入门 -> NPU 推理流程 |
| 已有 ONNX 模型 | 模型要求 -> ONNX 转 TFLite -> INT8 量化 -> 模型集成 |
| 模型运行失败 | 算子支持检查 -> 自定义算子 -> 常见问题 |

## 开发主线

```text
ONNX 模型
    |
    +-- 模型结构检查、TFLite 转换、INT8 量化、精度验证
    |
    v
RA8P1 平台配置
    |
    +-- 时钟配置、内存规划、模型存储选择
    |
    v
TFLM + Ethos-U55 NPU 部署
    |
    +-- 模型集成、编译烧录、推理验证、性能分析
    |
    v
应用集成
    |
    +-- RUHMI 与 RZ/V 系列芯片内容入口
```

## 部署前确认

- ONNX 模型已经在 PC 侧完成基准推理。
- TFLite INT8 模型的精度满足应用要求。
- 输入前处理、输出后处理与训练流程一致。
- 已确认模型算子支持情况、Tensor Arena 大小和模型存储位置。
- NPU、CPU、总线和外部存储相关时钟已经完成规划。
