# 常见问题

## 故障定位路径

```text
无法编译 -> 工具链、组件、模型数组、算子注册
无法启动 -> 链接地址、硬件配置、存储和时钟初始化
HardFault -> Tensor Arena、栈、指针、外部内存边界
模型初始化失败 -> 模型格式、schema、算子支持
结果错误 -> 前处理、布局、量化、后处理
性能不足 -> NPU 后端、时钟、存储、数据搬运
```

## 常见现象

| 现象 | 可能原因 | 排查方法 |
| --- | --- | --- |
| 模型加载失败 | 模型损坏或 schema 不匹配 | 校验模型长度、版本和 PC 加载结果 |
| Arena 分配失败 | 内存预算不足 | 记录所需 Arena 与可用区域，检查并发缓冲 |
| 输出全相同或异常 | 输入量化或布局错误 | 打印输入张量首尾样本、scale 和 zero point |
| 推理慢 | CPU fallback 或时钟低 | 记录算子后端、频率、存储位置和耗时 |
| HMI 无响应 | 推理占用任务或带宽 | 拆分任务，测量刷新与推理时间 |

排查时应一次只改动一个变量，并保存串口日志、模型版本、输入样本和工程配置。
