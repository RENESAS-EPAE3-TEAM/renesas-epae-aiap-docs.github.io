# 平台与软件架构

## 本章目标

理解 RA8P1 端侧 AI 工程中模型、运行时、NPU 与应用软件的职责边界。

## 架构关系

```text
应用任务
  |
  +-- 数据采集和前处理
  +-- TensorFlow Lite Micro (TFLM)
  |     |
  |     +-- 算子解析、Tensor Arena、模型调度
  |
  +-- Ethos-U55 NPU
  |     |
  |     +-- 支持算子的硬件加速
  |
  +-- 后处理、显示和业务控制
```

- **模型侧**：将 ONNX 模型转换并量化为设备可用的 TFLite 模型。
- **运行时**：TFLM 负责模型加载、张量内存和算子调用。
- **NPU**：Ethos-U55 为可支持的算子提供加速；不支持的算子可能由 CPU 执行，或需要调整模型。
- **应用侧**：负责输入采集、数据格式转换、结果解释及与 HMI 或控制逻辑的交互。

## 关键原则

模型能成功转换不等于能在目标板上正确、快速地运行。部署时应分别验证模型精度、算子支持、内存占用、实际执行后端和推理延迟。
