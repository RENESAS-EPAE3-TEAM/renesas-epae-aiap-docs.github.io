# 完整开发流程

## 开发主线

```text
准备环境 -> 准备 ONNX 模型 -> 转换 TFLite -> INT8 量化
     -> 检查算子 -> 配置时钟、内存和存储
     -> 集成 TFLM 与模型 -> NPU 推理 -> 验证与优化 -> 应用集成
```

## 阶段产物

| 阶段 | 主要产物 | 完成标准 |
| --- | --- | --- |
| 模型准备 | ONNX、TFLite、INT8 TFLite | PC 侧精度符合预期 |
| 平台配置 | 时钟、内存和存储设计 | 资源规划可实施 |
| 设备部署 | 可烧录工程和模型数据 | 设备能稳定推理 |
| 验证优化 | 测试记录 | 精度、延迟和内存满足目标 |

每个阶段出现问题时，优先回到上一阶段的可验证产物。这样可以避免将模型问题误判为硬件或运行时问题。
