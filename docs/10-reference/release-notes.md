# 发行说明

## v1.0.0 - 2026-08-05

这是 RA8P1 AI 应用开发指南的首个正式文档版本。

### 主要内容

- 建立从平台概览、MNIST 快速入门到模型部署和应用集成的完整教程结构。
- 整合 Keras 直接量化与 ONNX 经 onnx2tf 转换后量化的模型准备流程。
- 补充全整数量化接口、Representative Dataset、布局变化和 PC 侧精度验证要求。
- 完善 RA8P1 时钟、内存、模型存储、Vela 编译和 TFLM 集成说明。
- 根据 Vela 5.1.0 整理 Ethos-U55 TFLite 算子支持表、通用约束和专用约束。
- 增加 CPU fallback、自定义算子判断、编译烧录、性能优化和故障排查路径。

### 兼容性说明

- MNIST 参考工程记录的 Vela 版本为 4.2.0。
- Ethos-U55 算子支持章节依据 Vela 5.1.0 官方 `SUPPORTED_OPS.md`。
- 不同 Vela 版本的算子约束可能变化，部署时应使用项目固定版本生成报告并检查转换日志。

### 验证状态

- 文档通过 `mkdocs build --strict` 构建。
- MkDocs Material 构建版本固定为 9.7.7。
- 发布前未对所有硬件组合重新执行板端测试；实际工具和硬件组合以版本兼容表及各参考工程记录为准。
