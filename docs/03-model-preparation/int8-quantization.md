# INT8 量化与精度验证

## 为什么使用 INT8

INT8 量化通常可降低模型存储和运行时内存需求，并使模型满足 NPU 部署的精度格式要求。量化带来的精度变化必须用代表性数据验证。

## 操作步骤

1. 准备覆盖真实输入范围的 representative dataset。
2. 生成 INT8 TFLite 模型，并确认输入输出是否同样量化为 INT8。
3. 记录每个输入输出张量的 scale 与 zero point。
4. 使用同一批验证样本运行浮点基线与 INT8 模型。
5. 将设备输出与 PC 侧 INT8 参考结果比较。

## 常见误区

- 使用无法代表实际数据分布的校准集。
- 设备端仍按 FP32 范围写入 INT8 输入张量。
- 将输出的量化整数直接作为业务结果，未按量化参数解释。
