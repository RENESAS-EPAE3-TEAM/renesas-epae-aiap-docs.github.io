# 模型要求

## 在转换前记录模型接口

| 项目 | 需要确认的内容 |
| --- | --- |
| 输入 | 名称、形状、布局、数据类型、数值范围 |
| 输出 | 名称、形状、类别或数值含义 |
| 前处理 | 尺寸调整、颜色空间、归一化、量化 |
| 后处理 | 反量化、阈值、NMS、标签映射 |
| 算子 | ONNX 图中使用的算子和属性 |

## 设计约束

- 优先使用固定输入维度，避免动态维度直接进入嵌入式部署流程。
- 将前处理和后处理视为模型接口的一部分，避免仅复制推理调用而遗漏数据变换。
- 转换前检查算子支持情况；必要时在训练或导出阶段替换结构。
- 为量化准备具有代表性的校准数据，覆盖真实输入范围。
