# 开发前置条件

## 硬件

- RA8P1 开发板及其匹配的调试下载器。
- 可选的传感器、摄像头、显示屏或外部存储器件。
- 与实际板卡一致的电源、启动和连接配置。

## 软件

- 已验证版本的 FSP、IDE、编译器和调试工具。
- 与工程匹配的 TFLM、Ethos-U55 相关组件和模型转换工具。
- 用于模型处理的 Python 环境及转换依赖。

详细版本请维护在[版本兼容表](../10-reference/version-matrix.md)。不要仅以“最新版”作为工程依赖约束。

## 部署前清单

- [ ] ONNX 基线模型可以在 PC 上完成推理。
- [ ] 训练、PC 验证和设备侧前处理规则一致。
- [ ] 已准备参考输入和预期输出。
- [ ] 已确认模型输入输出形状、数据类型和量化参数。
- [ ] 已预估模型、Tensor Arena、栈和图形缓冲区的内存占用。
