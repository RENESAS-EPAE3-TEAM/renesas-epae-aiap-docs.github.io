# 运行第一个示例

## 目标

使用已验证的示例工程完成一次从编译、烧录到串口或调试输出查看的端到端推理。

## 操作步骤

1. 使用项目指定的 IDE 和 FSP 版本导入示例工程。
2. 检查目标板、调试器和构建配置是否与工程一致。
3. 编译工程，确认模型数据、TFLM 组件和算子注册均已加入构建。
4. 烧录并复位开发板。
5. 输入样例数据，记录输出类别、置信度或数值结果。

## 预期结果

- 编译无 Error，生成可烧录镜像。
- 设备可以启动，且推理调用返回成功。
- 输出与 PC 侧的参考输出在应用定义的容差内一致。

## 失败时优先检查

| 现象 | 首先检查 |
| --- | --- |
| 编译或链接失败 | 工具版本、模型数组、组件和算子注册 |
| 启动后 HardFault | Tensor Arena、栈、模型地址和外部存储初始化 |
| 输出明显错误 | 前处理、张量类型、量化参数和后处理 |

参见：[常见问题](../09-troubleshooting/common-errors.md)。
